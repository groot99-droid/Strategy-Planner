# Harald Hardrada — Leadership Focus Guide

**Shape:** Monitor
**Curve:** Ramp | **Conversion:** Conditional | **Condition cost:** Coastal-heavy map dependency

> The core loop is a stat check, not a build order. These guides fail hardest when written as sequences, because the player's real job is watching one number and responding to it.

## Setup
*Turns: 1 to roughly 25*

Establish the thing being monitored and the infrastructure that lets you respond to it.

- Name the watched stat on turn 1: Un-pillaged coastal tile inventory near current fleet position
- Establish its bands before it matters, so the player recognizes trouble the first time rather than the third.
- Build the response capacity. A monitor with no available response is just anxiety.

## Standing Loop
*Turns: 25 to end of game*

This replaces the turn list entirely. The guide is this loop plus the era checkpoints.

- Read Un-pillaged coastal tile inventory near current fleet position.
- Green band: continue current build. No action.
- Amber band: begin the correction now. Amber is the acting band; red is the failing band.
- Red band: the ability is off or about to be. Everything else is deprioritized until it clears.

## Era Checkpoints
*Turns: each era boundary*

Re-read the role. Monitor leaders change what the stat means across eras.

- Ancient/Classical: Longship raiding as primary income.
- Medieval/Renaissance: Still raiding, with diminishing returns per coast.
- Industrial/Modern: The pillage economy is obsolete; coastal defenses outclass raiders.
- Atomic/Information: Nothing.

## Abort branch
**Trigger:** Watched stat sits in the red band for more than roughly 15 turns with no recovery path.
- Stop paying the Coastal-heavy map dependency. If the bonus is unreachable, its price is pure loss.
- Rebuild as a generic civ around whatever the monitored strategy already produced.

## Fail state
The stat crossed into red and stayed. For Harald Hardrada, Pillage yields deplete per tile. The same coastline does not pay twice.

## Caveats
- Pillage yields deplete per tile. The same coastline does not pay twice.
- Raiding produces income but never territory, so the empire does not grow while the ability works.
- Landlocked or low-coast maps flatly disable the strategy.

## Guide must account for
- A parallel domestic build plan, since raiding alone never compounds.
- A trigger for when to stop raiding and start actually taking cities.
- A map viability check before the strategy is recommended at all.
